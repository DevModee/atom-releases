# Atom

Atom is a free Windows gaming performance app. This repository only hosts the official installers and checksums.

## Download

[Download the latest Atom for Windows (x64)](https://github.com/DevModee/atom-releases/releases/latest/download/Atom-x64.msi)

Every release includes a `SHA256SUMS.txt` file. To check your download in PowerShell:

```powershell
Get-FileHash .\Atom-x64.msi -Algorithm SHA256
```

The hash must match the one in `SHA256SUMS.txt` for that release.

## Requirements

- Windows 10 or Windows 11, 64-bit
- Administrator rights to install
